## Direction B: "Kinetic Editorial" (typography as the show)
Read 00_SHARED_CONTEXT.md and D_design_common.md first.
### Concept
A magazine-grade page where the type itself moves and teaches. Big, confident headlines in a variable font whose axes
animate with scroll (weight, width or optical size), split-text reveals, sentences that re-flow to show "the same request in
a different mode". The elegance IS the demonstration: the page reads like the best long-form editorial sites, not a SaaS page.
### Direction specifics
- Type: a characterful variable display face from Google Fonts with at least two axes (e.g. Fraunces with opsz/WONK/SOFT,
  or Roboto Flex/Recursive/Anybody with width+weight) paired with a quiet grotesque or humanist body. No Inter/Space Grotesk.
- Palette: light-first, paper-white with a cool or green-grey bias (not cream), ink text, ONE accent that is not terracotta
  or purple; dark theme designed, not inverted. Use colour-mix() for tints.
- Layout: asymmetric editorial grid with generous margins; running heads; marginalia; a sticky table of contents that
  highlights as you read. Mobile collapses to a single column with the same hierarchy.
- Signature moments (build at least these): (1) hero headline whose weight/width axis is tied to scroll position, with the
  compass drawn as thin ruled lines that rotate as the headline shifts; (2) the "Fourteen Stances" as a horizontal
  scroll-driven procession on desktop (vertical on mobile), each word set in the display face, the current stance's failure
  mode appearing in the margin; (3) the matrix as a text-only animation: click a stance and the four layer words rearrange
  with View Transitions / FLIP so the load-bearing one rises to the top; (4) a "mode shift" paragraph: one request,
  re-typed live under Oracle, Interpreter and Executor, showing how the sentence changes.
- Micro-interactions: link underlines that draw; cursor-aware subtle parallax on pull-quotes; reduced-motion disables all.
